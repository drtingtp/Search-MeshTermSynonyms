# Comments and feedback


## Discussion

1. Head to [Discussions](https://github.com/drtingtp/Search-MeshTermSynonyms/discussions) section.

1. Using the search bar, check if a particular topic has been discussed.

1. To start a new discussion, use the `New discussion` button.

    ![](/static/img/comment-new-discussion.png)


## Permalink

To reference a particular part of the main document in a discussion, you can choose to use the quote markdown symbol `>` ([documentation](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax#quoting-text)) or use a permalink.

A permalink references a specific commit in this repository, so it remains valid even if the document's content changes.

To obtain the permalink of a particular line of the document:

1. Head to the source code page of the document via this [link](README.md?plain=1).

1. Search and locate the line in the source code.

> [!TIP]
> 1. Use Ctrl + F to help you locate keywords.
> 1. Enable word wrap in the upper right corner.
>
>       ![](/static/img/comment-wrap-lines.png)

3. Once the line has been located, click the `...` button on the left side of the line > Choose `Copy permalink`.

    ![](/static/img/comment-permalink.png)

1. Within the post editor in Discussions or Issues, paste the permalink.

    ![](/static/img/comment-paste-permalink.png)

1. You can check if the permalink is working by switching to the Preview tab.

    ![](/static/img/comment-preview-permalink.png)
